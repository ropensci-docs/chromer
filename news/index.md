## chromer 0.8

CRAN release: 2024-03-27

## chromer 0.6

CRAN release: 2023-09-21

#### Minor changes

- Now using https rather than http for the API calls

## chromer 0.5

CRAN release: 2023-08-20

#### Minor changes

- Tiny change to documentation to avoid a problem on CRAN. (Issue
  [\#38](https://github.com/ropensci/chromer/issues/38))

## chromer 0.4

CRAN release: 2023-03-24

#### Minor changes

- Skip the tests on CRAN, so that it doesn’t give errors if the API is
  down.

- Added internal function to check if CCDB is down, and skip the tests
  when that’s true.
